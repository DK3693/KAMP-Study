# KAMP Study

**A machine-learning study portfolio covering regression, classification, clustering, and model evaluation.**

[한국어](README.md) · [Learning map](docs/LEARNING_MAP.md) · [Evaluation notes](docs/MODEL_EVALUATION.md) · [Sources](THIRD_PARTY_NOTICES.md)

The study materials connect linear and polynomial regression, logistic regression, SVMs, tree ensembles, clustering, PCA, cross-validation, hyperparameter search, and imbalanced-class evaluation.

Six course notebooks are included with their original textbook attribution and redistribution notice. They are instructional examples from *으뜸 데이터 분석과 머신러닝* (revised edition), not presented as independently authored algorithms. Notebook execution outputs and local metadata have been removed.

Additional notes summarize wine classification, bank-deposit prediction, customer clustering, and oversampling exercises. The repository emphasizes the relationship between data preparation, model selection, and interpreting evaluation metrics.

See the Korean overview for notebook links and environment setup.
