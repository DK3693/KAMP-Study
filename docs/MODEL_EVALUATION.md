# 모델 평가와 실험 구성

## 데이터와 전처리

먼저 예측 대상과 입력 특징을 구분하고, 학습용과 평가용 데이터를 분리합니다. 스케일링처럼 데이터에서 값을 학습하는 전처리는 학습 데이터에 맞춰 적용합니다. Pipeline으로 전처리와 모델을 묶으면 교차검증에서도 같은 흐름을 사용할 수 있습니다.

## 평가 목적에 따른 지표

| 문제 | 확인할 지표·내용 |
|---|---|
| 회귀 | 예측 오차와 결정계수, 실제값과 예측값의 관계 |
| 이진 분류 | 혼동행렬, Precision, Recall, F1, ROC-AUC |
| 다중 분류 | 클래스별 결과와 macro/weighted 평균 |
| 군집화 | 군집 구조, 군집별 특징, 평가 지표의 정의와 가정 |

클래스가 불균형한 데이터에서는 전체 정확도와 함께 소수 클래스의 결과를 확인합니다. ROC에는 예측 클래스만이 아니라 모델의 연속적인 점수나 확률을 사용합니다.

## 교차검증과 파라미터 탐색

학습 자료는 교차검증과 GridSearchCV를 통해 여러 설정을 비교합니다. 비교할 때는 데이터 분할과 평가 지표를 동일하게 유지해야 설정에 따른 차이를 해석할 수 있습니다. 평가용 데이터는 마지막 성능 확인에 사용합니다.

## 오버샘플링

SMOTE 계열 실습은 소수 클래스 표본을 보강하는 방법을 다룹니다. 재표본화는 학습 데이터에 적용하며, 교차검증에서는 학습 fold 안에서 수행해야 평가 fold의 정보가 학습 과정으로 들어가는 일을 막을 수 있습니다.

## 결과 기록

실험 결과에는 데이터 분할, 모델 설정, 지표와 실행 환경을 함께 기록합니다. 이 공개 정리에는 재실행하지 않은 수강 자료의 점수를 개인 성능 실적으로 옮겨 적지 않았습니다.
