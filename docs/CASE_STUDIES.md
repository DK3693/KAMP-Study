# 응용 실습 주제

## 와인 분류

수강 자료는 와인 종류를 구분하는 문제와 품질 등급을 예측하는 문제를 다룹니다. 종류 분류와 품질 예측은 목표가 다르므로 결과를 따로 해석합니다. 데이터 분포, 표준화, Random Forest·부스팅·신경망 등의 비교가 주요 학습 내용입니다.

별도의 Wine 예제에서는 화학적 특징으로 와인 클래스를 구분하고, 결정 트리·배깅·Random Forest·AdaBoost와 특성 중요도를 살펴봅니다.

## 정기예금 예측

은행 데이터의 고객 특징과 가입 여부를 이용한 이진 분류 예제입니다. 전처리, 로지스틱 회귀, 계층화 교차검증과 표본 재구성 과정을 함께 다룹니다. 소수 클래스의 재현율과 정밀도를 구분해 해석하는 데 초점을 둡니다.

## 고객 군집화

K-means·DBSCAN 및 관련 군집 모델을 이용해 고객 특징에 따른 그룹을 비교합니다. 군집 수, 특징 스케일, 밀도 기준과 범주형 특징의 처리가 주요 비교 지점입니다.

## 모델 튜닝

SVM의 커널·C·gamma, 결정 트리와 앙상블 모델의 설정을 바꾸며 교차검증 결과를 비교하는 예제입니다. 같은 평가 절차 안에서 설정을 비교하고 최종 평가를 분리하는 관점으로 정리했습니다.
